<shell-maker-end-of-prompt>
`enable-local-variables` defaults to `t`, which prompts you to confirm "unsafe" local variables (ones not marked safe by their defcustom). `:all` skips that confirmation and applies all file/dir-local variables without asking.

It's not the default because local variables can execute arbitrary code (e.g., `eval` in `.dir-locals.el`), which is a security risk for untrusted files. For your own dotfiles/projects, `:all` is fine.

# Plan: Fix ein (Emacs Jupyter) Keybindings

## Context

`C-<up>`/`C-<down>` (ein's default cell navigation) conflicts with macOS system bindings (Mission Control). The user wants `S-<up>`/`S-<down>` for cell navigation and `M-<up>`/`M-<down>` for paragraph movement, accepting the one-time obsolescence warning from ein.

## File to Modify

`shared/emacs.nix` — the ein keybinding block (~line 200)

## Changes

Replace the current block:
```elisp
;; ein notebook navigation:
;; S-Up/Down: jump between cells, M-Up/Down: paragraph movement (global default)
(with-eval-after-load 'ein-notebook
  (keymap-set ein:notebook-mode-map "S-<up>" #'ein:worksheet-goto-prev-input)
  (keymap-set ein:notebook-mode-map "S-<down>" #'ein:worksheet-goto-next-input))
```
